# State of Europe

Public briefing and provenance-tracked data on Europe’s post-2022 defence buildup.

**Live:** https://timnooren.github.io/state-of-europe/

To view locally:

```bash
python3 -m http.server 8765
# open http://127.0.0.1:8765/
```

Sources and series live under `sources/` and `data/`. Working notes for agents are in `AGENTS.md`.
